# About 页面图片说明

## `member-sidebar-bg.png`

- 用途：五个成员个人页左侧栏的雨夜山村背景。
- 来源：依据项目现有封面画面及用户提供的页面截图进行 AI 局部编辑。
- 编辑内容：移除画面中央人物，并补全雨幕、屋顶、墙面和台阶。
- 透明背景：否。
- 建议显示位置：成员页左栏，居中裁切，使用 `background-size: cover`。
- 限制：不替代或覆盖原始封面图；不用于人物头像。

## `members/*.png`

- 用途：制作组总览卡片和成员个人页头像。
- 来源：由各成员提供。
- 透明背景：以各原始文件实际通道为准。
- 建议显示位置：正方形容器内居中显示，使用 `object-fit: cover`。
- 限制：未经成员确认，不覆盖原图或执行不可逆裁切。
