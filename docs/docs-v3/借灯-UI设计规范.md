〇、视觉母题（为什么这样设计）

《借灯》的故事核心是"**白灯**"——雨夜门前出现一盏**没有火焰却泛着白光**的纸灯笼，它代表"掩饰"（虚假的传说，恐怖的人性）。

所以整款游戏的视觉只讲一个对比：

| 元素 | 感觉 | 用法 |
|---|---|---|
| **冷夜**（深蓝黑、雨、雾） | 压抑、悬疑、荒废 | 所有页面的底色、场景背景 |
| **白灯**（惨白暖光） | 唯一的光、焦点、真相 | 强调色、发光热点、标题、关键线索 |

三个场景（祠堂 / 村口 / 老宅）虽然画面不同，但都遵循**同一套色板 + 同一种雨 + 同一盏白灯的光源**，所以玩家切场景时感觉是"同一个雨夜里的不同地方"，不会突兀。

> 这条母题也回答了你的诉求："不一定完全一致（不呆板），但要整体氛围统一。" —— 统一靠的是**色板、雨、灯、字体**这四样不变的东西，而不是每页长得一模一样。

## 一、色彩规范（Design Tokens）

> 现有各 CSS 各写各的颜色（`game.css` 的 `--accent:#d8c6a4`、`menu.css` 的 `#d8c9ad`、`authorize.css` 的浅色底），要**全部收拢成下面这一套**，全站引用同一份。

### 1.1 统一色板

| 变量名 | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#07090e` | 页面最深底色（场景最暗处） |
| `--color-bg-elevated` | `#0d1118` | 面板/卡片底 |
| `--color-bg-panel` | `rgba(13,17,24,0.92)` | 文本框、侧栏半透明底 |
| `--color-lamp` | `#f5f0e3` | **白灯的光**（最亮，高光/热点光晕） |
| `--color-paper` | `#ece7dc` | 正文纸白 |
| `--color-paper-dim` | `#cfc8b8` | 次级文字 / 旧纸 |
| `--color-old-paper` | `#d8cbb0` | 旧纸 / 寻人启事纸色 |
| `--color-accent` | `#d8c6a4` | **强调暖金**（木纹、旧物、描边） |
| `--color-accent-deep` | `#b89b6e` | 深金（木纹、按钮 hover） |
| `--color-mist` | `#8fb8ce` | 雾蓝（冷光、次级点缀） |
| `--color-rain` | `#5d7f9e` | 雨蓝（雨丝、冷调） |
| `--color-muted` | `#a4a9b1` | 次要说明文字 |
| `--color-line` | `rgba(230,225,213,0.16)` | 分隔线 / 细边框 |
| `--color-danger` | `#c17a74` | 警示 / 错误 |
| `--color-cinnabar` | `#a6534a` | **朱砂红**（印章 / 关键真相 / 门外声音） |

### 1.2 用色规则

- **底色永远用冷**（`--color-bg` 一族），**强调永远用暖**（`--color-lamp` / `--color-accent`），形成"冷夜里一盏灯"的对比。
- **朱砂红只用在三处**：关键真相线索、错误提示、门外的声音——不能到处用，用多了就"不吓人"了。
- 登录/注册页**取消浅色底**，统一成暗色雨夜底（这是你提的"背景虚化处理"的落地方向）。

## 二、字体规范

### 2.1 字体族

| 层级 | 字体 | 用途 |
|---|---|---|
| **标题**（游戏名"借灯"、章节名、场景名） | `"Songti SC", "STSong", "SimSun", serif` | 中式庄重，字距大 |
| **正文**（剧情 / 人物对白） | `"Songti SC", "SimSun", "Noto Serif SC", serif` | 宋体，可读 |
| **小字 / 说明 / 旁白细节** | `"Kaiti SC", "STKaiti", "KaiTi", serif` | **楷体**（你建议的小字改楷体） |
| **UI 功能标签**（按钮、顶栏、系统提示） | `"Microsoft YaHei", "PingFang SC", system-ui, sans-serif` | 清晰无衬线 |

> 采纳你的建议：**进入页下面那行看不清的小字、以及所有"说明性小字"，统一用楷体**，既好看又有中式手写感，还能和正文宋体区分开。

### 2.2 字号阶梯

| 层级 | 字号 | 字距 | 行高 |
|---|---|---|---|
| 游戏名"借灯" | 24px 粗 | 0.18em | — |
| 章节名 / 场景名 | 18–20px | 0.15em | — |
| 正文（剧情/对白） | 17–21px（随视口） | 0 | 1.9 |
| 系统 / 旁白 | 15px | 0 | 1.8 |
| 小字 / 说明（楷体） | 12–13px | 0.05em | 1.6 |
| 按钮 / 提示 | 14px | 0.02em | — |

## 三、间距与圆角

- **间距用 8px 网格**：4 / 8 / 12 / 16 / 24 / 32 / 48（面板内边距 20–24px，卡片间距 14px）。
- **圆角统一**：面板 `8px`，按钮 `6px`，输入框 `6px`，小标签 `4px`。
- **边框统一**：`1px solid var(--color-line)`，强调态用 `var(--color-accent)`。

## 四、组件规范

### 4.1 文本框 / 剧情面板（重点，你提了要"换底色 + 加点缀"）

- **底色**：`var(--color-bg-panel)` 半透明深蓝黑，叠一层极淡的纸纹（用 CSS 径向渐变模拟旧纸的暖，不要真贴图）。
- **边框**：`1px solid var(--color-line)`，圆角 `8px`。
- **点缀（角花）**：左上角用 `::before` 放一个**小小的白灯/印章角花**（暖金色，3–4px 大小即可），不要喧宾夺主。
- **正文**：纸白宋体，行高 1.9；**旁白/系统文字**加一条左侧 `2px` 暖金竖线区分。
- **宽**：桌面下剧情框这个我不知道现在容器如何 按着容器来吧

### 4.2 按钮

| 类型 | 样式 |
|---|---|
| **主按钮**（继续 / 保存） | 纸白底 `--color-paper` + 深色字 `#11151c`，hover 提亮 |
| **次按钮**（返回 / 取消） | 透明 + `--color-accent` 描边，hover 加暖金底 5% |
| **禁用** | opacity 0.5 + `cursor: wait` |

### 4.3 反馈条

- 左侧 `4px` 色条区分类型：正常=暖金、错误=警示红、成功=灰绿、警告=土金。

### 4.4 顶栏 / 章节名

- 常驻顶部，深色底，章节名用宋体 `18px`、字距 `0.15em`，右侧放[背包][地图][成就]。

### 4.5 发光热点（呼应"白灯"）

- **光晕**：`--color-lamp` 白灯色，柔和的 radial 光晕，带**呼吸**动效（见下）。
- **已调查后**：光晕变暗 + 一个淡灰"已查看"标记，不再重复发光。

### 4.6 覆盖层（详情 / 背包 / 拼图）

- 统一深色半透明底 + 圆角 8px，打开时背景锁死；关闭回到原状态。

### 4.7 白灯光源（场景照明 · 只定"光"，不画灯笼）

白灯是《借灯》全游戏唯一、最有辨识度的暖光源。规范层只定"光"的规格，**不做具体灯笼造型**（竹骨 / 穗 / 纸纹等细节交给杨梦的正式背景图实现）。

| 元素 | 规格 |
|---|---|
| **光晕** | radial 渐变，中心 `--color-lamp`（最亮）向外衰减到透明；半径约为场景短边的 0.5–0.7；呼吸动效（opacity 0.85↔1，约 2.5s，见 §五） |
| **光柱** | 从光源垂直向下的锥形光（`clip-path` 收窄），暖白低透明度（≈0.3），自上而下渐隐，照亮下方地面 / 物体，传达"灯悬在上方" |

- **位置**：每场景 1 处主光源（祠堂：门 / 梁上；村口：电杆 / 屋檐；老宅：门后），**不得遮挡任何发光热点、线索或对白区域**。
- **作用**：统一三场景的照明方向与冷暖，玩家切换场景时仍感觉"同一个雨夜"（呼应 §〇 母题）。
- **禁止**：规范层不画具体灯笼造型，不定义竹骨 / 红穗 / 纸纹，这些是美术图的事。

## 五、动效与过渡规范

采纳你"雨滴不断流淌"的建议，动效只做三类、克制不花哨：

| 动效 | 实现 | 说明 |
|---|---|---|
| **雨滴** | 背景雨丝垂直缓慢下移（CSS 或轻量 JS） | 低透明度，不干扰阅读 |
| **白灯呼吸** | 灯的光晕 opacity 在 0.85→1 间缓慢起伏（约 2.5s） | 只用在灯/热点上 |
| **场景切换** | 200–400ms 淡入淡出 | **三个场景用同一个过渡，解决"切换突兀"** |

> 铁律：动效不触发眩晕（不做大面积快速位移），尊重系统"减少动态效果"设置。

## 六、响应式（三视口）

| 视口 | 规则 |
|---|---|
| **1280px** | 完整布局：顶栏 + 场景 + 侧栏 |
| **768px** | 顶栏入口压缩成图标，侧栏变两列 |
| **390px** | 单列，剧情条可占约 50% 屏高，顶栏入口缩到右上汉堡 |

**文字安全区**：关键线索、发光热点不能被对白框/按钮遮住（这是 A3 视觉验收的核心）。

## 七、可读性与无障碍（"现在太浅色看不清"）

- 正文与背景对比度 **≥ 4.5:1**；小字楷体字号 **≥ 12px**。
- **探索区**的物体标签、热点提示：在场景图上要有足够对比——深色半透明底衬 + 灯白字，不能直接用浅色字浮在亮背景上（现在"探索字体太浅色"）。
