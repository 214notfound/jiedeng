# V3 事件链实现补充

本补充用于明确正式运行时的事件边界，不新增接口类型。

- 探索模块完成对象调查后发送 `OBJECT_INVESTIGATED`，携带 `objectId` 和对应 `resultFactIds`。
- 全局协调器将外部事件交给剧情运行时校验。
- 状态模块只接收剧情运行时生成的正式状态提交，不由探索模块直接写入 `STORY_FACT_RECORDED`。
- 对话继续使用 `NPC_TALK_PROGRESS` / `NPC_TALKED`。
- V3 小游戏使用已登记的 `MINIGAME_RESOLVED`，且 `resultFactIds` 只能包含一个允许结果。
- 旧版 `map-puzzle` 继续使用 `MAP_PUZZLE_COMPLETED`，不改变 V2 契约。

若本文与旧版接口描述存在差异，以本补充和正式代码的事件链为准。
