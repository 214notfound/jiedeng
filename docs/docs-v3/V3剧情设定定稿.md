## 1. 借灯民俗源流

**定案**：借灯的本意就是「活人借死人的名义」。石涧村有一路宗族丧仪——客死他乡、尸骨无归的人，家里在门口点一盏灯，把死者的名字继续「借」在户口、田契、名额上。「死人借活人的脸」是这路丧仪在代代口传中被恐怖化异化后的壳子；雨夜（当地连阴雨）、借脸、宗族老人讲述，都是这个异化的副产物。

**依据**：大纲主题句「借灯从来不是鬼在借，是活人借死人的名义」；TODO「由招魂灯、路祭、宗族丧仪演化而来」。

**影响**：纯背景设定，不进 Node / factId。王阙后来「利用」恐怖版（大纲「他把自己最恐惧的东西复制出来」），即他本人也在「借死人的名义」切割责任。

## 2. 苏禾社会说辞

**定案**：公司不说「苏禾走了」，而是顺着村民已有的猜测，暗示「苏禾没死，躲起来继续对抗（就是白灯客）」，用安保伪造的手机轨迹制造「她仍在活动」的假象。村民半信半疑、无人有实锤；苏禾无在世近亲（父母已故），无人坚持报案；警方按「成年人自行离村、无犯罪迹象」不予立案。

**依据**：大纲「有人猜他（白灯客）接过了苏禾没做完的事，但没有人能证明两人认识」；设计稿 S04「自行离村的轨迹与她最后的调查相冲突」、M14「手机轨迹由安保系统伪造」。

**影响**：进入 `investigate-su-trail`（苏禾线）与 `investigate-su-death-scene` 的「要讲清的事」；具体台词 / 叙述由卢正松、杨梦按此定案展开。

## 3. 恐吓工程参数

**定案**：三装置各有独立供电 + 缺陷——白灯=拒签户照明支线（断支线即灭）、广播=废弃小学配电（拔定时器即停）、湿脚印=矿山排水线槽（关泵 / 断水即消失），汇聚于旧电房总闸（D03），备用供电柜（D05）解释远程重启。湿脚印借用的矿山排水系统，与通往矿井内部的「旧排水洞」同属一套矿山水系；但拆鬼阶段只暴露机械缺陷、不暴露它通向事故现场，到重返矿井（M00–M02，已在 father-company-truth 之后）才连成一线。

**依据**：大纲「湿脚印→利用矿山排水系统制造」、陈晋年坠入的「排水暗洞」；设计稿 D00–D03、M02。

**影响**：进入 `haunting-network-puzzle`（拆鬼小游戏）与 `x-showdown-chase`（终局追逐）的规则；恐怖规则同时是玩法规则，由卢正松按此实现。

## 4. 伪造地点

**定案**：公司没把苏禾手机带出矿区伪造，而是就在矿井附近用信号放大器 / 伪基站刷出「她向村外移动」的记录。破绽：伪造的「离村」轨迹起点不是她住处，而是矿井入口——安保只知道她最后出现在矿井（人就是他们推进去的），只能从「最后真实位置」开始编。玩家比对方向即可识破。

**依据**：大纲「小周在矿井里抢走苏禾手机」、苏禾被留在矿井深处；设计稿 M14「在竖井边找到苏禾手机取卡痕迹和安保操作记录」。

**影响**：进入 `su-death-chain-complete` 证据链（手机轨迹伪造是其中一环），与 S04「轨迹异常」互证。
