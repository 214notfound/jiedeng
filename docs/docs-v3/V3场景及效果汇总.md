## 一、统一设计规则（所有场景通用）

1. **大场景优先**：人物站在哪个大场景，就画哪个大场景当背景；能画进环境里的对象一律做成「热点」，不做平铺网格。
2. **少用子场景**：只有「物理上独立的隐藏空间」（地窖、暗层）才加子场景；「一个台面堆 ≥4 个线索」才加放大层。原则：能不改就不改。
3. **对象 = 热点**：每个可调查对象是一个 44×44 点击热点，视觉对象矩形可更大；热点中心间距 ≥144px（390px 视口缩放下仍 ≥44px）。热点点击高亮由 UI 覆盖层实现，不画入背景。
4. **玩法只做入口＋出口**：拆鬼 / 路线解谜 / 追逐，三个小游戏各做「入口页 + 出口页」，中间玩法过程跳过，交给卢正松与高冰轩。
5. **多结局多场景**：五个结局各画一张独立场景图。

## 二、画布与坐标规范

- 画布 **1280×720**，16:9，`contain` 满屏不裁切，图片与热点同步缩放。
- 坐标两套并写：**像素**（1280×720 参考画布）＋ **百分比**（`中心x/1280×100 , 中心y/720×100`，取整）。
- **点击目标**：44×44px；**中心距**：≥144px；同一台面 ≤3 个热点，≥4 个改「1 点热点 → 点击 → 放大」。
- **UI 占位**（背景图不裁切，但这些区域允许被覆盖层遮挡）：顶部条 `y≈0–60`（返回键），底部阅读/对话框 `y≈600–720`。关键对象尽量落在 `y≈120–560` 中部带。
- 拍点编号（G00、R01、T06…）是**文档追溯键**，不是运行时 ID；`objectId` 一律留 `TBD` 由卢正松冻结。
