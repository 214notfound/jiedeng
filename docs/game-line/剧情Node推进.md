## V1 剧情流程 Node 表（仅内容与进度）

> 本表只定义“这一段发生什么、玩家此时知道什么、剧情推进到哪里”。不定义状态字段、存档结构、触发器或代码实现。V1 的表层主线始终是“查怪事—查公司—碰到旧事”，身份问题只作为逐步升高的暗线。

### 第二阶段：村口

| Node | 内容                                                         | 玩家当前获得的认知                                          | 进度作用                     |
| ---- | ------------------------------------------------------------ | ----------------------------------------------------------- | ---------------------------- |
| V00  | 进入村口：空屋、搬迁告示、施工痕迹和被雨泡烂的旧标语共同呈现村庄衰败。 | “闹鬼”发生在一个正在被开发、搬空的村子里。                  | 建立现实冲突背景             |
| V01  | 路口和墙面贴着苏禾的寻人启事：村小学教师，近期失踪。         | 苏禾不是被提问出来的人名，而是村里正在发生的现实事件。      | 苏禾线自然出现               |
| V02  | 与小卖部老板闲聊“村里为什么这么空”。对方提到项目进村后一直谈搬迁，很多人已经走了。 | 村庄没落与当前开发项目直接相关。                            | 引出公司线                   |
| V03  | 老板认出主角，语气突然变冷，顺口称他为“B工程师”。            | 工作证上的B得到外部呼应；主角以前可能来过这里。             | 身份暗线第一次抬头           |
| V04  | 主角继续问最近的白灯。老板说怪事是在项目推进后重新频繁出现的，但不肯断言是不是公司做的。 | “鬼”和项目时间上存在可疑重合。                              | 让查鬼自然转向查公司         |
| V05  | 话题转到苏禾。老板说她一直反对仓促搬迁，也在查白灯、广播和矿区旧线，后来突然不见了。 | 苏禾把“怪事”和“公司问题”连接起来。                          | 建立近期悬案                 |
| V06  | 小X插话，强调成年人失踪未必和项目有关，并催主角别把每件事都扯到公司。 | 小X开始限制调查解释的方向。                                 | 第一次软性干预               |
| V07  | 与拒签户谈为什么不搬。对方提到房、祖坟和十几年前那场事故，认为有些地方“不是赔钱就能算完”。 | 村子的抵触不仅是利益问题，还有未解决的旧事。                | 引出十七年前事故             |
| V08  | 小X故意用“早搬走就没这么多事”“该赔的不是都赔了”之类的话刺激对方。村民愤怒，谈话被迫中断。 | 小X看似只是公司立场强硬，实际成功阻止主角继续追问旧事故。   | 明确他的“打断深挖”模式       |
| V09  | 与一名年老村民聊旧事故。对方提到陈家当年也出了事，那个小女孩最宝贝一颗蓝玻璃珠，“掉沟里都要捡回来”。 | 主角随身玻璃珠与陈家旧事产生第一次隐式呼应。                | 妹妹暗线抬头，但仍可视为巧合 |
| V10  | 老人在观察主角某个动作时突然叫出“A”，随即自己否定：“不对，A早死了。” | A作为十七年前的旧人第一次出现；老人是否认错无法判断。       | 身份暗线第二次抬头           |
| V11  | 继续闲聊得知，当年的说法是学校后山“山体滑坡”死过孩子，此后村子越来越败。 | 获得官方/民间表层版本的旧事故。                             | 为后续翻案建立基准           |
| V12  | 小X再次催促结束谈话，把注意力拉回“我们是来查最近的怪事，不是翻十几年前的账”。 | 玩家开始注意到：每当旧事碰到主角，小X就会收紧调查范围。     | 加深小X疑点                  |
| V13  | 从三处村民处取得残缺手绘地图并复原。                         | 得到当前村庄空间；陈家老宅成为可到达地点。                  | 完成村口阶段                 |
| V14  | 地图指向陈家老宅。小X主动提醒主角试试此前那把旧钥匙。        | 小X似乎也希望主角去陈家，但理由仍可解释为“那里可能有线索”。 | 进入老宅                     |

### 第三阶段：陈家老宅

| Node | 内容                                                         | 玩家当前获得的认知                                          | 进度作用                      |
| ---- | ------------------------------------------------------------ | ----------------------------------------------------------- | ----------------------------- |
| O00  | 到达荒废的陈家老宅。小X给的无标记旧钥匙可以开门。            | 钥匙与陈家存在真实联系；小X把主角带到这里不是完全偶然。     | 老宅入口                      |
| O01  | 调查家庭照片：十几岁的哥哥A、年幼的妹妹和父亲。A当时面容完整。 | A是真实存在的人；照片外貌与现在主角并不直接相符。           | 保留“A不是我”的合理解释       |

| O03  | 调查身高刻痕，确认事故时期A约十七岁，妹妹才是小学生。        | 修正“事故死者都是小孩”的模糊印象，建立兄妹年龄关系。        | 完成A人物基础轮廓             |
| O04  | 调查送葬名单/旧丧葬记录。妹妹明确死于十七年前事故后的那段时间，A也被村里作为死者送葬。 | 村民“ A早死了 ”有现实依据。                                 | 建立A已死的当前结论           |
| O05  | 主角把工作证、蓝玻璃珠、老钥匙和屋内线索短暂并置，但无法解释彼此关系。小X立刻把话题转回：“这里可能留下了和最近怪事有关的东西，先找完再说。” | 身份问题第一次明显上升；小X第一次显得急于压下它。           | 从暗线转向可感知冲突          |
| O06  | 屋外雨声加重，门外出现细微动静。                             | 借灯规则开始回扣。                                          | 恐怖段落开始                  |
| O07  | 门外有人隔着门叫“A”。                                        | “A”从旧记录中的死者名字，变成一个正在被呼唤的名字。         | 第一轮身份恐怖高潮            |
| O08  | 小X立即提醒“别答”，并催促主角离开门边。声音再次出现后消失。  | 无法判断门外是在叫死去的A、叫这间屋子的旧主人，还是叫主角。 | 保持多解                      |
