# V2 场景容器与坐标规则

> 依据：PRD V2、V2 界面状态切换约定、卢正松三场景对象交接表、杨梦三张 1280×720 示意图。
> 当前实现：`assets/js/exploration/game/exploration-view.js` 与 `assets/css/exploration/exploration.css`。

## 1. 坐标基准

- 三场景草图基准为 `1280 × 720`。
- 场景比例统一为 `16:9`。
- 坐标原点为实际场景图片区域左上角。
- x 向右，y 向下。
- x/y 使用 0—100 的百分比。
- 热点中心与美术对象锚点重合。
- 当前对象表坐标是参考值，不是最终冻结坐标。

## 2. DOM 结构

正式页面保持 `#game-scene` 为场景入口，探索视图在其中挂载：

```html
<section id="game-scene">
  <div class="scene-coordinate-space">
    <div class="exploration-hotspots"></div>
  </div>
</section>
```

背景图片和 `.exploration-hotspots` 必须使用同一个 `.scene-coordinate-space` 作为定位父元素。页面外边距、顶栏高度、反馈区和阅读区不参与坐标换算。

当前场景舞台通过 `aspect-ratio: 16 / 9` 保持比例；最终背景图接入后应作为该容器的背景/图片层，不得另建第二个坐标容器。

## 3. 图片显示规则

当前建议冻结：

```text
完整显示 1280×720 画布
保持 16:9
优先使用 contain 或等价的无裁切方案
图片与热点同步缩放
```

若最终改为 `cover`，必须重新确认裁切偏移和热点映射，不能只修改 CSS 的 `object-fit`。

## 4. 响应式规则

| 内容宽度 | 规则 |
|---|---|
| 1280px | 完整 16:9 场景，验证所有对象和阅读安全区 |
| 768px | 保持 16:9，顶栏可压缩，热点点击区不得明显缩小 |
| 390px | 单列布局，保持 16:9，覆盖层使用屏幕内边距，关键对象不得被文本遮挡 |

杨梦规范中提出的汉堡入口属于后续导航交互决策；在 controller 确认前，不通过 CSS 单独隐藏现有顶栏按钮。

## 5. 对象与坐标职责

| 内容 | 负责人 |
|---|---|
| 对象在图片中的位置、构图、安全区 | 杨梦 |
| x/y 数值、对象 ID、点击结果 | 卢正松 |
| 容器比例、缩放、裁切、CSS | 高冰轩 |
| 状态切换和背景锁定 | 罗晨菲/controller |

旧宅门与门外声音可以复用视觉锚点，但不增加一个可见的神秘人热点。小 X 在村口参与对白，不新增第四个村民热点。

## 6. 严格自检

### DOM

- [ ] 热点定位父元素是场景内部容器。
- [ ] 场景不会因为阅读区高度变化而改变坐标。
- [ ] 不存在第二套场景容器。
- [ ] `#game-scene` 与 `#exploration-actions` 仍由 controller 统一控制。

### 比例与坐标

- [ ] 1280×720 不变形。
- [ ] 768px 和 390px 不横向溢出。
- [ ] 图片和热点同步缩放。
- [ ] 坐标仍使用对象表中的稳定 ID。
- [ ] 暂定坐标没有被标记为最终坐标。
- [ ] 每个最终坐标注明草图版本、图片尺寸、点击范围和确认人。

### 视觉与失败

- [ ] 热点不遮挡关键线索。
- [ ] 阅读区和反馈区不遮挡必需对象。
- [ ] 热点标签在亮背景上有足够对比度。
- [ ] 图片加载失败时仍有文字提示和返回入口。
- [ ] 页面不显示坐标、对象 ID、commandId 或 fact ID。
