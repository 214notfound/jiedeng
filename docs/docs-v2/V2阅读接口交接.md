# V2 阅读接口交接

> 适用范围：剧情 presentation 与 NPC conversation 共用的逐段阅读视图。
> 当前实现：`assets/js/core/game-ui.js`。
> 当前数据适配：`assets/js/core/reading-contract.js`。

## 1. 职责边界

阅读器只负责显示文本、维护本地阅读位置和发出玩家操作回调。它不调用 `enterStory()`，不提交事实，不提交 `NPC_TALKED`，不修改 `storyCheckpoint`，不读写存档。

| 行为 | 负责人 |
|---|---|
| 逐段显示文本 | 阅读器 |
| 点击继续、移动阅读索引 | 阅读器 |
| 点击剧情 action | 阅读器回调，controller/game-flow 接收 |
| NPC 对话是否完成 | 对话模块 |
| 提交 `NPC_TALKED` | 对话模块通过 host/game-flow |
| 决定下一个 Node | 剧情引擎 |

## 2. 规范化输入

阅读器接收规范化对象，不直接解析剧情或 NPC 原始业务结构：

```js
{
  mode: "story" | "conversation",
  speaker: "老板",
  items: [
    {
      id: "block-or-line-id",
      kind: "narration" | "system" | "dialogue",
      text: "玩家看到的原文"
    }
  ],
  actions: [
    {
      actionId: "confirm-wake-context",
      label: "确认当前处境",
      actionType: "advance"
    }
  ],
  metadata: {}
}
```

原始字段转换由 `adaptStoryPresentation()` 和 `adaptConversationInput()` 完成。剧情使用 `blockId`，NPC 使用 `lineId`，进入阅读器后统一为 `items[].id`。

NPC 分支选择使用 `adaptConversationChoiceInput()`，并明确声明 `readingState: "choice"`。该输入只包含一段玩家可见提示和 2 至 4 个已冻结选项；每个选项的 `actionType` 必须为 `choice`。阅读器只回传所选 `actionId`，不决定分支结果。

## 3. API

```js
const reader = createReadingView({
  onComplete(result) {},
  onAction(actionId, metadata) {},
  onClose() {}
});

reader.open(input);
reader.update(input);
reader.next();
reader.close();
```

- `open(input)`：校验并开始新的阅读会话，显示第一项。
- `update(input)`：替换为新的阅读会话，等价于重新 `open`。
- `next()`：只推进本地索引；最后一项结束时触发一次 `onComplete`。
- `close()`：清空视图并触发 `onClose`，不触发 `onComplete` 或剧情事件。

`onComplete` 返回：

```js
{
  mode: "story" | "conversation",
  finalItemId: "最后一个 blockId 或 lineId",
  metadata
}
```

`onAction` 只返回剧情提供的 `actionId`，不能依据按钮文案判断逻辑。

## 4. 强制规则

- 一次只显示一个 item，顺序不可改变。
- 剧情 action 必须等所有 items 读完后才显示。
- 同一会话的 `onComplete` 只触发一次。
- 异步 `onAction` 执行期间按钮禁用，防止重复提交。
- 异步提交期间 `#game-actions` 标记 `aria-busy="true"` 并显示“正在处理，请稍候……”；成功后清除，失败后显示“操作没有完成，请重试。”并重新启用按钮。
- NPC 文本中的 `【老板】`、`【你】`、`【小 X】`、`【旁白】`、`【系统提示】` 仍是输入正文的一部分；渲染时只识别开头完整的 `【…】` 标签，并把它移入橙光式姓名牌。无标签或标签不在开头时保留原文且不猜角色。
- NPC Choice 只接受已经由对话模块提供的 `prompt`、`choices` 和业务标识；组件不创建选项、不解释选项含义、不猜字段。
- `blockId`、`lineId`、`commandId`、Node ID 和 fact ID 不显示给玩家。
- 阅读器关闭不等于取消事件；是否提交取消由业务适配器决定。

- [x] item ID 和 action ID 重复时拒绝输入。
- [x] 剧情 `blockType` 只接受 `narration`/`system`。
- [x] NPC `lineId` 正确映射为 item ID。
- [x] `next()` 不调用 game-flow。
- [x] action 只在末尾出现；Choice 只显示业务方提供的 2 至 4 个选项。
- [x] 连续点击只产生一次完成回调；异步 action 执行期间不可重复提交。
- [x] `close()` 不产生完成回调。
- [x] 页面 DOM 不出现技术标识，动态正文通过 `textContent` 渲染。
- [x] 组件不写 facts、检查点或存档。
